# CONFLUX CORE — Submission copy (draft)

**Title:** CONFLUX CORE — One Reactor. Four Minds.

**Description:** CONFLUX CORE is a cooperative browser puzzle for 2–4 players. Your crew must stabilize a giant reactor by aligning four linked mechanical ring stations. Every adjustment changes your station and shifts the next one in the opposite direction, so solving the puzzle depends on coordination. Create a room, share a code with friends, communicate in real time, and survive three escalating rounds before the reactor collapses. The experience includes a cinematic interactive arena, an optional real-time WebGL2 3D view, and a compact interface for desktop and mobile.
